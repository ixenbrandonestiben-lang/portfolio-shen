# Portafolio Interactivo - Brandon Estiben

Portafolio web modular, escalable y de alto rendimiento que fusiona la estética de la mecánica automotriz con la arquitectura de software moderna.

## 🚀 Estructura del Proyecto
- `index.html`: Estructura semántica principal.
- `css/`: Estilos modulares (Variables, Base, Universo, Componentes, Secciones).
- `js/`: Lógica desacoplada (Main, Animaciones GSAP, IDE, Araña Canvas, Cubo 3D, Flipbook).

## 🛠️ Cómo ejecutar
1. Asegúrate de tener todos los archivos en sus carpetas correspondientes.
2. Abre el archivo `index.html` en tu navegador. 
3. *(Recomendado)* Usa una extensión como "Live Server" en VS Code para una mejor experiencia de desarrollo.

## 🎨 Personalización
- **Temas**: Modifica los colores en `css/variables.css`.
- **Contenido**: Edita el texto directamente en `index.html` o los snippets en `js/ide.js`.
- **Datos del Cubo**: Actualiza el objeto `techDetails` en `js/cube.js`.
